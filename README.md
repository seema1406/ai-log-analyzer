# AI Log Analyzer

AI Log Analyzer is a React-based web application that helps analyze log files efficiently. Users can upload log files and inspect log data in a cleaner and more organized way.

---

## Features

* Upload and analyze log files
* Simple and responsive UI
* Fast log inspection
* React-based frontend
* Easy to run locally

---

## Tech Stack

* React.js
* JavaScript
* HTML5
* CSS3
* Node.js
* npm

## Installation

Clone the repository:

```bash
git clone https://github.com/seema1406/ai-log-analyzer.git
```

Move into the project directory:

```bash
cd ai-log-analyzer
```

Install dependencies:

```bash
npm install
```

---

## Run the Project

Start the development server:

```bash
npm start
```

If your project uses Vite:

```bash
npm run dev
```
